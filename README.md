# Facturación DTE — propuesta de proyecto

Propuesta personal de una aplicación para apoyar a emprendimientos y personas en la preparación y gestión de documentos tributarios electrónicos en El Salvador.

## Estado actual
El repositorio contiene documentación inicial y un archivo de exclusiones de Git. No incluye una aplicación ejecutable, generación de DTE, firma electrónica ni comunicación con servicios de Hacienda.

## Alcance previsto
- Organización de datos de emisor, clientes y productos o servicios.
- Preparación de documentos y validación de campos.
- Consulta del historial y estado de documentos.
- Evaluación de una integración con los servicios y entornos oficiales correspondientes.

## Próximos pasos
Definir requisitos, verificar la documentación oficial vigente, seleccionar tecnologías y construir un prototipo con datos ficticios. La implementación deberá distinguir generación, firma, transmisión y respuesta del servicio receptor.

El nombre del proyecto expresa su objetivo; este repositorio todavía no acredita emisión válida de documentos fiscales.
